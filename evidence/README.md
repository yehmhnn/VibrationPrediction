# Selected saved evidence

Byte-identical metadata, configurations, small histories and diagnostic summaries copied from original completed runs. Original logs and checkpoints remain untouched. `docs/provenance/PHASE2B_MANIFEST.json` records source paths and SHA-256 hashes; the Phase2A experiment map remains authoritative.

Manifests include reserved recording assignments as metadata. No signal arrays or reserved-test predictions were read or copied in this phase. Absolute paths are historical provenance, not portable launch instructions. Checkpoint binary files and raw/processed signals are deliberately absent. Seed42 baseline results are historical reused runs, not fresh overnight repeats. Preserved CSV/JSON precision is unchanged; narrative summaries use three decimals.
